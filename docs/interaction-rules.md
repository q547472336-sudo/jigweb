## 通用动作

| 动作 | 成功后 | 取消／失败 |
|---|---|---|
| 打开卡片 | 普通 ready 或恢复 active | 不可访问时留在来源或返回 |
| 首次有效拖动 | ready → active，写最近玩过；挑战开始计时 | 挑战启动失败回原位、不计时 |
| 收藏 | 全站同步状态和统计 | 取消登录无变化；请求失败回滚 |
| 保存 | 本地保存，登录用户继续云同步 | 标明失败层并重试 |
| 完成 | 幂等结算、记录、完成 UI | 保留棋盘并重试，不伪造结果 |
| 创建 | 同请求 ID 返回同一作品 | 保留输入，重试不重复创建 |
| 受限能力 | 登录后执行一次原动作 | 取消恢复原上下文 |

## 卡片与普通模式

卡片优先级为普通 active／paused、历史完成、未开始；挑战和房间不覆盖普通百分比。ready 不写记录。已完成作品打开即退出仍为已完成，首次有效拖动后显示进行中 0%。收藏为叠加状态，收藏按钮不触发卡片跳转。

保存状态为 `idle → local-saving → local-saved → cloud-syncing → synced`，任一层可进入对应 error。离线保留本地保存。版本冲突暂停覆盖，用户选择前两份均保留。

提示只高亮所选片目标格 3 秒；打乱把所有未固定片整齐放回左右托盘；边框和底版只影响本人视图。缩放、画布和原图位置不改变拼图数据。普通暂停阻止拖动；退出 active 先同步，失败时说明可能未同步。

## 登录

邮箱验证码为 6 位，10 分钟有效，60 秒后可重发；每邮箱每小时最多 5 次，每码最多 5 次失败。新码使旧码失效，错误不透露邮箱是否已有账户。登录 continuation 仅执行一次；退出清除账号会话和界面缓存，账号数据与游客空间隔离。

## 创建

单页顺序：选图 → 解码校验 → 裁剪 → 名称／描述／分类 → 片数／形状／可见性 → 预览 → 创建。上游缺失时下游禁用并解释。更换图片清除旧裁剪和预览，但保留文本设置。

默认 36 片、经典凹凸、仅自己可见；自定义为行×列。公开作品可分享；私有作品不显示一起拼或分享。离开未提交内容时确认，确认离开丢弃内存草稿。

## 今日挑战

游客为练习，登录用户为正式；开始前明确标识。正式状态为 `ready → starting → active ↔ pausing/paused → submitting → completed`。首次有效拖动先请求服务端开始，确认前碎片不移动。

暂停先遮挡，服务端确认后停表；失焦请求暂停，返回仍需手动继续。断网遮挡但继续计时，重连读取服务端状态。暂停覆盖画布、托盘和原图。跨 Asia/Shanghai 00:00 的未完成局失效。缺题显示未开放，题目下线终止在途局。同日所有尝试配置和初始 seed 相同且无打乱。

结算先保存尝试和最佳成绩再返回排名。同一尝试重试不重复写入；较差成绩不替换最佳；同分按完成时间、用户 ID 排序。

## 多人房间

建房前普通 active 局先同步快照，失败不建房。房间是独立副本，不回写普通存档；私有作品禁止建房。

状态为 `creating → waiting → starting → active → completed`，非终态可进入 `reconnecting`，超时进入 `ended`。容量 2～4，至少两人在线且仅房主开始；开始后拒绝新成员，旧成员可重连。

房主主动离开立即转移，掉线 60 秒后转移。等待 30 分钟、全员离线 10 分钟或 active 24 小时后结束。锁由服务端授予，租约 5 秒、每秒续租；没有锁不能提交位置。旧版本更新拒绝，固定片不因租约解除。

至少取得一次锁并提交合法位置变化才算参与。观看者无完成；实际参与者提前离开后，房间最终完成仍获得去重完成和通知。多人没有全房暂停和打乱；提示、边框、底版、原图和缩放只影响本人。

## 列表与个人页

搜索空词不请求。多个词取 AND，每词可匹配名称、描述或作者。筛选变化重置第一页；加载更多失败保留已有数据。失效作品不继续显示私有缩略图。我的完成按作品去重；最近玩过按有效拖动更新，三种模式均可产生记录。个人列表卡片仍进入普通模式。

## 异常恢复顺序

1. 保护可用数据和棋盘。
2. 确认服务端权威状态和权限。
3. 成功后才显示已保存、已创建、已完成或已入榜。
4. 重试沿用请求、尝试或结算 ID。
5. 无法恢复时说明原因，并提供返回或重开入口。
