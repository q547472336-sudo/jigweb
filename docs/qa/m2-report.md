# M2 个人内容闭环 · 开发候选验收报告

日期：2026-09-17。结论：**M2 本地开发候选可运行，尚不能标记为生产验收完成。** 当前版本可用于继续 UI 联调和产品走查；Supabase、真实邮件、RLS、对象存储以及完整冲突选择仍是后续实施项。

## 已完成链路

- 发现：首页、搜索、分类、集合列表和卡片直达拼图；搜索支持多词 AND、分类、片数与稳定排序。
- 普通拼图：确定性碎片、左右托盘、放置、进度、暂停、工具、本机 IndexedDB 保存，以及登录用户的服务端版本化保存。
- 账户：邮箱 6 位 OTP 登录；10 分钟有效、60 秒重发、每小时 5 次发送、每码 5 次失败；资料编辑、双邮箱验证码更换和退出。
- 个人内容：收藏、我的作品、我的收藏、我的完成、最近玩过、个人统计和通知读取。
- 创建：上传格式／大小／像素检查、五种比例居中裁剪、最长边 2048px、行列与总片数检查、公开／私有、幂等创建、创建后开始或回我的作品。
- 内容受理：帮助、反馈受理号、举报 24 小时去重接口、通知分页和已读接口。
- 权限：私有作品对非所有者统一返回 404；个人列表和资料接口要求登录身份。

## 未满足的生产验收

1. 当前后端是单进程内存开发适配器；重启会清空账号、作品、收藏、通知和云存档。`x-user-id` 仅用于本地契约联调，不是生产会话安全方案。
2. Supabase PostgreSQL/Auth/Storage、SQL migration、RLS、真实邮件和私有图片短期签名地址尚未接入，因此不能宣称跨设备持久化或越权防护已通过生产验证。
3. 存档能拒绝旧版本，但登录迁移的双份选择弹窗、7 天备份和离线队列尚未完成。
4. 当前拼图交互是桌面 HTML 网格开发版；经典凹凸形状、按 3px 有效拖动判定、画布坐标吸附和 500 片性能门槛仍需前端专项实现。
5. 图片在浏览器完成中心裁剪；服务端真实解码、动画 WebP 拒绝和异步派生图尚未完成。
6. 通知读写已接通，但内容下线／反馈处理的维护命令与事件生产者尚未接通。
7. 自动化浏览器截图在当前 Windows 沙箱被浏览器进程权限阻止；已完成代码审查和 HTTP 渲染检查，但不能把它替代为视觉 QA。视觉验收留给 T22 或可运行浏览器环境。

## 阶段判断

- 可继续：产品走查、普通玩法联调、M3 挑战和 M4 多人契约开发。
- 不可宣称：M2 生产完成、真实云存档、生产登录安全、最终画布性能和视觉验收。
- 下一优先级：先完成 Supabase adapter 与 RLS，再由前端完成存档冲突选择和 Canvas 引擎；两项可并行。
