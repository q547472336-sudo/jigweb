## 关闭规则

1. A～D 全部为 `PASS` 才将 M2 标记为 DONE。
2. 缺 Supabase 环境、真实邮件或浏览器设备时标 `BLOCKED`，写清责任人与解除条件，不使用“基本完成”。
3. 本地 memory adapter 的通过证据只能证明契约与 UI 联调，不能替代持久化、RLS 或跨设备验收。
4. 发现需求冲突回到 PRD V1.1 和 interaction-rules.md，不由实现自行改规则。
