## T21 已验证范围

`npm run test:m3-m4` 在单机同一 Node 进程中模拟两个独立用户，已覆盖：

- 游客只能创建练习挑战，正式挑战用户可以开始、保存、完成和重试结算。
- 挑战快照旧版本被拒绝，正式成绩进入排行榜。
- 房间创建、加入、非房主不能开始、房间开始和公开房间读取。
- 同一碎片的锁竞争返回 `LOCK_TAKEN`；有效锁可以续租。
- 旧 `stateVersion` 的房间事件返回 `STALE_EVENT`。
- 两名实际移动过碎片的成员都获得一次多人完成记录和一次通知。
- 私有作品不能创建多人房间；非成员只能读取房间，不能操作棋盘。
