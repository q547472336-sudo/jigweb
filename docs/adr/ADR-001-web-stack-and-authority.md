# ADR-001：桌面 Web 技术栈与服务端权威边界

状态：Superseded by [ADR-0001](0001-platform.md)。日期：2026-09-12。

## 决策

采用 TypeScript 的 Next.js 桌面 Web 作为应用基座，Canvas 负责拼图画布，PostgreSQL 负责业务一致性，对象存储负责图片，实时通道只传输房间事件。前端负责渲染、输入和本地缓存；后端负责权限、服务器时间、版本、幂等、结算和房间锁。

## 原因

产品是桌面网站，需求包含 URL 路由、公开发现、私有资源和多客户端协作。服务端权威可防止客户端伪造挑战成绩、覆盖存档或同时取得同一碎片。把挑战和多人建立在普通拼图领域服务之上，能复用配置、快照和版本而不复制引擎。

## 取舍

需要实现会话、资源授权和实时连接等基础设施，开发复杂度高于纯本地 Demo；V1 因此使用本地适配器先开发前端。后续 ADR-0001 已选定 Supabase 为生产目标。

## 后续验证

以契约测试证明：版本冲突不覆盖、重复创建返回相同 ID、私有资源越权被拒绝、挑战时间由服务器事件计算、同一碎片只有一个有效锁。若选定平台无法满足任一条，必须新增 ADR 修订本决策。
